# Web-Claude Project Instructions (Disaster-Recovery Copy)

This file is a verbatim copy of the web-Claude project instructions
as maintained in the architect's claude.ai project settings. It
exists for disaster recovery purposes: in the event the architect
loses access to the claude.ai project (account loss, account
migration, claude.ai service disruption, etc.), the contents of
this file can be pasted as the first message of a fresh Claude chat
to bootstrap a new web-Claude session with the same project
instructions.

**This file is NOT part of the normative project specification.**
It does not appear in the orientation chain (CLAUDE.md,
refamiliarize.md, working_notes_for_authors.md). It is a
stand-alone safety copy.

**The canonical version of these instructions is maintained in
claude.ai's project settings.** This in-repo copy may lag behind
the canonical version if the architect updates the project
instructions without re-syncing. The architect is responsible for
keeping this file current with whatever is in claude.ai.

**Disaster recovery procedure.** To resurrect a web-Claude session
from scratch (e.g., after losing the claude.ai project):

1. Start a new Claude chat.
2. Paste the contents of this file (starting from "BEGIN PROJECT
   INSTRUCTIONS" below) as the first user message.
3. Follow it with a brief request: "You are web-Claude per these
   instructions. Please orient yourself by fetching the repo
   files referenced in the orientation chain."
4. Web-Claude should respond by fetching CLAUDE.md, the charter,
   refamiliarize.md, and working_notes_for_authors.md from the
   repo, and orienting from there.

After bootstrapping, the new web-Claude session should be
functionally equivalent to a fresh session within the original
claude.ai project, modulo any project instructions updates that
haven't been synced to this file.
