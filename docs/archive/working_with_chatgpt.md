## Reliable ChatGPT Workflow for Multi-Document Projects

**1. One Chapter (or Task) Per Session**

* Start a *new chat* for each chapter or section you work on.
* Focus the chat on a single document or topic to avoid context drift.

**2. Use Projects and Upload Files**

* Use OpenAI’s **Projects** feature if possible.
* Upload each chapter or major section as its own file.
* Set clear project instructions for style, audience, and naming conventions.

**3. Name Files Clearly and Consistently**

* Use descriptive, numbered filenames (e.g., `01-intro.md`, `02-background.md`, etc.).
* Refer to files/chapter numbers explicitly in your prompts.

**4. Work in Canvas for Editing**

* Open the specific file in Canvas when editing.
* Highlight only the part you want ChatGPT to change.
* Review and accept/reject suggestions using version history/diff.

**5. Regularly Summarize and Reset**

* At the end of each session, summarize changes and decisions.
* Use this summary to “prime” a new session, resetting ChatGPT’s context when needed.

**6. Keep a Master Copy & Use Git**

* Always maintain a single “master” version of your files outside ChatGPT.
* Use Git for versioning: commit changes after each AI edit.

**7. Check and Merge Edits Manually**

* Before updating your master file, compare (diff) ChatGPT’s changes with your last version.
* Manually accept only intended edits.

**8. Backup Regularly**

* Make backups or snapshots at major milestones.

**9. Re-upload or Summarize After Major Changes**

* If you reset or start a new session, upload the current version or paste a summary to regain context.

**10. Be Explicit—Never Assume**

* Always tell ChatGPT which file/chapter you’re working on.
* Confirm before making large or irreversible edits.

---

**Bonus:**

* If ChatGPT starts to “go bad” (confusion, forgetting, errors), *stop and reset* with a new chat or session.
* Use summaries or re-upload files to resume progress without losing your place.

---

This workflow maximizes safety, clarity, and efficiency for large writing or technical projects!
